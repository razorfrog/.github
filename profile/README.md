# Razorfrog Web Design

We design, build and look after WordPress websites for businesses and organizations. More at [razorfrog.com](https://razorfrog.com).

## Free WordPress plugins

Our plugins on [WordPress.org](https://profiles.wordpress.org/razorfrog/#content-plugins), with their code here:

| Plugin | What it does |
|---|---|
| [Cinza Grid](https://github.com/razorfrog/cinza-grid) | Lightweight, filterable post grids built with Isotope |
| [Cinza Slider](https://github.com/razorfrog/cinza-slider) | Lightweight sliders and carousels built with Flickity |
| [Easy Content Lists](https://github.com/razorfrog/easy-content-lists) | Shortcodes that list pages, posts, taxonomies and tags |
| [Product Dropdown Widget for WooCommerce](https://github.com/razorfrog/woo-product-dropdown-widget) | A widget that lists WooCommerce products in a dropdown menu |
| [Bulk Convert Post Format](https://github.com/razorfrog/bulk-convert-post-format) | Converts every post in a category to a chosen post format |
| [Spinitron Player](https://github.com/razorfrog/spinitron-player) | A live stream player for radio stations, with the current show from Spinitron |

Found a bug or have a question? Post in the plugin's WordPress.org support forum, or open an issue here.
